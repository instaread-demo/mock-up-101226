UFT One 2023: Top 11 Features and Enhancements

by Ankur Jain | Last Updated On May 15, 2023 | New Features & Walkthrough, UFT Versions | 0 comments
Listen to audio version of this article
Sponsored by
0:00 / 2:09
Instaread

Micro Focus (now OpenText) has introduced UFT One 2023 in April 2023, only 8 months after the release of UFT One 2022. This latest version includes several notable improvements in areas such as AI and usability.

Check the most notable additions and enhancements that UFT One 2023 has to offer.

AI-based enhancements

  • You can now configure UFT One to identify objects using the AI Object-Detection (AIOD) Cloud Service. Given that AI based testing needs a lot of resources and procuring local machines could quickly run into huge costs, this may prove to be a game changer.  A cloud based service is a great feature addition from Micro Focus (now OpenText).
  • Regular expressions are now supported for AI-based object identification.
  • Ordinal object identification is now more fine tuned for AI based tests.

Usability Enhancements

There are lots of enhancements done on the usability front.

  • It is now possible to define a default view in UFT One whenever you access GUI actions or scripted components.
  • Export and Import of tests is now easier since you can now export the list of folders in which UFT One searches for tests. A Resource Path type option is also introduced in this version whereby you can save resources as absolute or a relative path.

Miscellaneous Updates

  • You can now run your mobile tests on cloud browsers provided by Digital Lab.
  • Recovery Scenarios can now handle recovery triggers for a 64-bit application crash.
  • Action names can now be more than 31 characters.
  • Action Sheet Dictionary tab is introduced in the Properties pane. It would display the relationships between the actions and data sheets in your test.
  • With Automation Object Model (AOM) scripts, you can now launch UFT One as any Windows user and not just the logged-in user.
  • Microsoft 365 web is supported via the web add-in while Microsoft 365 desktop is supported via the UIA Pro add-in.

Digital Lab is the next generation of UFT Mobile and henceforth all references for UFT Mobile will be rebranded as Digital Lab. The UFT Mobile Add-in for Local Devices is now named Digital Lab Lite for Local Devices.
